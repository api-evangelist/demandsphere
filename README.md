DemandSphere is a unified AI search visibility platform (founded 2010, Y Combinator S10) that tracks brand presence across traditional search engine results pages, AI search engines (ChatGPT, Gemini, Perplexity, AI Overviews, AI Mode), and agentic surfaces. Its modular products cover DemandMetrics SERP analytics, DemandMetrics for Gen AI (LLM visibility and citation tracking), DemandSphere Agents workflow automation, Analytics AX log-file analytics, and Search Intelligence, a BigQuery data warehouse. The DemandSphere REST API (v5.0) exposes rank tracking, ranking trends, keyword groups, local rankings, landing matches, search-engine summaries, and site hierarchy data as JSON over api-key authentication, across 200+ markets and 10+ search engines, and is complemented by a first-party Model Context Protocol (MCP) server for agent access.

**Areas:** Company · SEO · Search Intelligence · SERP Analytics · AI Search · LLM Visibility · Rank Tracking · Analytics · MCP

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for DemandSphere: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
